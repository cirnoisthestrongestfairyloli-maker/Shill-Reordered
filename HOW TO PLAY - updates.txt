Abstract Reordered - how to play and stay updated
=================================================

Always start the game with "Abstract Reordered.exe" (not Ikemen_GO.exe).
It checks for updates, downloads only what changed, then starts the game
(with Discord Rich Presence if Discord is open).

First time
  Put "Abstract Reordered.exe" in an empty folder (or in an existing copy of the game)
  and double-click it. A fresh install downloads about 1.5 GB once; later updates are small.

Good to know
  - Your save folder (controls, settings, stats, replays) is never overwritten.
  - If Windows says "Windows protected your PC": More info -> Run anyway (the exe isn't signed).
  - No internet? Click "Play anyway" to play the version you have.
  - Close the game before updating; files in use can't be replaced.
  - Something wrong? updater\launcher.log says what happened.
  - Files you add yourself are left alone, but edits to the build's own files
    (e.g. data\select.def) get replaced on the next update.
