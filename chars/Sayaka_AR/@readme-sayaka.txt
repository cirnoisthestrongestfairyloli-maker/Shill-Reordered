Button Layout
--------------
X - Light Punch
Y - Medium Punch
Z - Hard Punch
A - Light Kick
B - Medium Kick
C - Hard Kick
S - Taunt


Unique System
--------------
*Dash			→→

*Back Step		←←

*Air Jump		↑(in the air)

*Air Dash		→→(in the air)

*Air Back Dash		←←(in the air)

*Super Jump		↓↑

*Guard Cancel		K+K(while guarding)(lv.1

*Magia Cancel		P+P or →+P+P(lv.1
	Entering a command when a normal/special attack hits or guards forces it into a neutral
	(or fast dash) state. You can activate it only once with one combo.

*Reserve Reversal	Enter command while down
	If you enter either dash, jump or special move while down, 
	you will move to each action immediately after getting up. 
	(Super jump is not applicable.)


Command Moves
--------------
*Matagi Shooting Sword	↓+C(in the air)

*Aero Dive		↓↙←+K(when super jumping)


Throw
--------------
*Blue-R			→+X+Y

*CC Sword		→+X+Y(in the air)


Special Moves
--------------
*Oratorio		↓↘→+P(can do in the air)

*Scherzo		↓↘→+K

*Aria			↓↓+S


Hyper Moves
--------------
*Sforzando		↓↘→↓↘→+P(lv.1

*Arioso			↓↙←→+P(lv.1

*Grandioso		↓↘→+P+K(in the air)(lv.3

*Tempestoso		↓↙←↓↙←+K(lv.1

*Affettuoso		↓↙←P+K(After the darkness awakening)(lv.1
	Darkness awakening..Activated when some conditions are met.
	(Use too much magic/Be cornered/Die teammate etc..)
