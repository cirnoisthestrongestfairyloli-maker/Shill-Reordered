3.FEATURES
====================================
- This char features a platform switching system similar to 
Bleach DS, pressing the "z" button will switch from a 
forground to a background perspective and visa versa,
you can only hit your opponent whilst being on the same
platform as them, this can only be used correctly
against a char who also is supported with this feature, 
currently only bleach characters produced by the 
bleach mugen team.

- comes with both ENG and JAP voices that can
be switched in the config.txt
====================================
4.LAYOUT
====================================
The layout this char is only 5 buttons, and if you don't like it tough >:) :
with the exception of z now being for line jumping!

    a b c
    x y z

a = Medium Attack b = Strong Attack  c = Block
x = Light Attack  y = FlashStep      z = line jump (has to be set in config.txt)
